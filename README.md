# Kinora Homes — Variation 2 Interactive Storybook

Complete Next.js App Router website using TypeScript, CSS, and lucide-react.

## Start

1. Extract the ZIP into a **new** folder. Do not merge with the earlier project.
2. Open the extracted `kinora-website` folder in VS Code.
3. Run `npm install` and `npm run dev`.
4. Visit http://localhost:3000.

## Pages
Home, Our Home, Our Approach, Life at Kinora, About Us, Careers, Contact.

## Design
Built to reproduce the approved Variation 2 art direction with colorful storybook imagery, rounded type, watercolor-inspired sections, illustrated home, and clickable room labels. This is a responsive web implementation, not a pixel-for-pixel copy of the concept board. Some images are cropped from the approved concept art and should be replaced with actual authorized photos before launch.

## Content and safety
This site is a draft. Verify all program details, policies, claims, accessibility, and any public-facing images before publishing. Avoid displaying identifying information about residents. Contact form opens the visitor's mail application; it does **not** submit or store messages on a server. No job vacancies are implied. Do not publish exact home address without considering residents' privacy.

## Images
Images are in `public/`; `kinora-logo.png` is the user's final logo. Page content is in `app/*/page.tsx`; styling is in `app/globals.css`.
